Search Syntax

Advanced ways to filter results from the search bar.

  • word— matches comments containing this word. Multiple bare words match any of them (OR).
  • "exact phrase"— matches the exact phrase.
  • +word— comment must contain this word.
  • -word— comment must not contain this word.
  • author:name or user:name— filter by comment author.
  • flair:text— filter by flair text.
  • score:>10, score:<5, score:>=10, score:<=5, score:=3— filter by score.
